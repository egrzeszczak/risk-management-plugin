Context by definition is:
* the situation within which something exists or happens, 
* and/or infromation that can help explain the situation. 

Anything can be percieved as context, but for this process we can consider a thorough description of the project. To make it easier for you and the tools you use to digest this context, the best practice is the Five Ws method[^1]:

* Who?
* What?
* When?
* Where?
* Why?

Journalists use these as the fundamental five questions of explaining what is happening. We can extend this method for this process by asking detailed questions? The more detailed the questions, the more detailed the answers, and therefore, the context.

You can start by answering the questions below.

### Questions 

* Who is engaged in this?
* Who manages this?
* Who has what role?
* Who is/will be supporting this?
* What is this about?
* What tools are you using (or want to use)?
* What are you sure of? What are you unsure of?
* What you like/dislike about this?
* When is this starting? 
* Does this has an end date? If yes, when should this end?
* Where is this project being ran (i.e. location, provider)?
* Where would you want this ran?
* Which direction would you want this to go?
* Why this project?
* Why is this being considered?

[^1]: https://en.wikipedia.org/wiki/Five_Ws.
